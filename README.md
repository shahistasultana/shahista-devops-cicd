# Shahista DevOps CI/CD Project

## Project Objective
Build and deploy a Python Flask web application
using an automated CI/CD pipeline.

## Technologies
- Linux
- Python
- Flask
- Git and GitHub
- Docker
- Jenkins
- AWS ECR
- AWS EC2

## Project Goals
1. Develop a Python web application.
2. Manage code using Git and GitHub.
3. Write automated tests.
4. Build a Docker image.
5. Automate CI/CD using Jenkins.
6. Deploy the application on AWS EC2.
